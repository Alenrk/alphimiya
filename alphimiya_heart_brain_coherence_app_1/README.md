# ✨ الفيمياء ALPHIMIYA® — توافق القلب والعقل · طفرات جاما · تزامن الفصين

تطبيق Streamlit متقدّم لتحليل بيانات Muse 2 (عبر Mind Monitor) من زاوية
"التيقظ والتكيف العصبي" — مستوحى من أبحاث د. جو ديسبنزا والدراسات العامة
حول التأمل، توافق معدل ضربات القلب (HRV Coherence)، وتزامن نصفي الدماغ.
مقدَّم كأداة عملية ضمن منهجية **ALPHIMIYA®** (الفيمياء) التي تدمج مراحل
الخيمياء الداخلية بمفاهيم علم الأعصاب.

---

## 1) المؤشرات الأربعة

| المؤشر | المصدر | الطريقة |
|---|---|---|
| **توافق القلب والعقل** | `PPG_IR` + `Heart_Rate` | استخراج IBI من ذروات PPG الخام (إن سمح معدل العينات) أو من عمود Heart_Rate، ثم حساب نسبة توافق HRV بأسلوب Welch PSD مستوحى من منهجية HeartMath، مدموجة مع تزامن معدل النبض مع قوة ألفا+ثيتا الجبهية |
| **طفرات جاما** | `Gamma_*` | كشف القمم الفجائية عبر Z-score مبني على وسيط/MAD متحرك (مقاوم للتشويش)، مصنّفة إلى متوسطة/قوية/استثنائية |
| **تزامن الفصين** | `RAW_*` أو `[Band]_*` | تماسك طيفي حقيقي (scipy.signal.coherence) من الإشارة الخام إن سمح معدل العينات، وإلا ارتباط منزلق بين قوى الموجات كبديل |
| **مؤشر التكيف العصبي** | مركّب من الثلاثة أعلاه | متوسط مرجّح (أوزان قابلة للتعديل) عبر نوافذ زمنية متحركة، مع تحديد "لحظات الذروة" التي تتجاوز عتبة معينة |

> ⚠️ **هذه مؤشرات استكشافية من تصميم هذا التطبيق**، وليست خوارزميات طبية
> معتمدة. راجع قسم "ملاحظات منهجية" أدناه للتفاصيل الكاملة.

## 2) تقرير PDF قابل للتنزيل

يظهر زر **"✨ توليد تقرير PDF لهذه الجلسة"** في قسم مستقل وبارز أعلى الصفحة
(مباشرة تحت لوحة المؤشرات الرئيسية، قبل التبويبات التفصيلية). يولّد التقرير:

- عنوان وفقرة **ملخص محمّسة وتحفيزية** تُبنى ديناميكياً من أرقام الجلسة الفعلية
  (لا نصوص جاهزة ثابتة).
- المؤشرات الأربعة كاملة (توافق القلب والعقل، طفرات جاما، تزامن الفصين، مؤشر
  التكيف العصبي) بأرقامها وطريقة الحساب المستخدمة لكل منها.
- رسم بياني زمني لمؤشر التكيف العصبي المركّب (يتطلّب متصفح Chrome/Chromium
  متاحاً محلياً لتصدير الصورة عبر kaleido — التقرير يُنشأ بدونه بأمان إن لم يتوفر).
- قسم **"أبرز لحظات الذروة"** — قصة سردية محمّسة لأقوى طفرات غاما ولحظات
  تجاوز عتبة التكيف العصبي، مرتّبة زمنياً بطابع {mm:ss} لكل لحظة.
- قسم ملاحظات منهجية بأسلوب علمي محايد (غير محمّس عمداً) يوضّح حدود كل مؤشر.

بخط Amiri المُدمج مع تشكيل وترتيب RTL صحيح (نفس تقنية التطبيق الأول)، والعناوين
والملخص فقط بالأسلوب المحمّس — الجداول الرقمية والملاحظات المنهجية تبقى دقيقة ومحايدة.

### لأفضل النتائج عند التسجيل بـ Mind Monitor

في إعدادات Mind Monitor قبل بدء الجلسة، فعِّل:
- **Include PPG** — لتفعيل الحساب الدقيق لتوافق HRV من ذروات النبض الفعلية.
- **Include Raw EEG** — لتفعيل التماسك الطيفي الدقيق لتزامن الفصين.
- تسجيل **3–5 دقائق فأكثر** — تحليل HRV الترددي يحتاج نافذة زمنية لا تقل عن دقيقة تقريباً ليكون ذا معنى إحصائي.

بدون هذه الخيارات سيعمل التطبيق أيضاً معتمداً على بدائل تقديرية (عمود
`Heart_Rate` وقوى موجات EEG)، وسيوضح لك بنفسه أي طريقة استُخدمت فعلياً لكل
مؤشر عبر شارات "طيفية دقيقة" مقابل "تقديرية" الظاهرة في الواجهة.

## 5) النشر على Streamlit Community Cloud

1. أنشئ مستودع GitHub وارفع إليه كل ملفات هذا المجلد (`app.py` وبقية ملفات
   `.py`، `requirements.txt`, `packages.txt`, `.streamlit/`, ومجلد `assets/fonts/`
   بالكامل — يحتوي خط Amiri اللازم لتوليد تقرير PDF بالعربية).

```bash
git init
git add .
git commit -m "النسخة الأولى من تطبيق توافق القلب والعقل"
git branch -M main
git remote add origin https://github.com/USERNAME/heart-brain-coherence-app.git
git push -u origin main
```

2. اذهب إلى [share.streamlit.io](https://share.streamlit.io)، اضغط **New app**،
   اختر المستودع والفرع `main`، وضع **Main file path** = `app.py`، ثم **Deploy**.
3. سيقرأ Streamlit Cloud تلقائياً `requirements.txt` (وpackages.txt، وإن كان
   فارغاً وظيفياً هنا فلا ضرر من وجوده) ويشغّل التطبيق على رابط عام خلال دقائق.
4. أي `git push` لاحق إلى `main` يُعاد نشره تلقائياً.

### بدائل نشر أخرى
- **Hugging Face Spaces:** Space جديد بنوع "Streamlit"، بنفس الملفات.
- **خادمك الخاص:** `streamlit run app.py --server.port 80 --server.address 0.0.0.0`

## 6) ملاحظات منهجية مهمة (يُنصح بقراءتها)

- **توافق القلب والعقل (Heart-Brain Coherence):** نسبة التوافق مبنية على مبدأ
  "قوة الذروة ضمن نطاق 0.04–0.26Hz مقابل باقي الطاقة الطيفية" — مبدأ مشابه
  لمنهجية معهد HeartMath المنشورة، لكنه **تبسيط مستقل من تصميم هذا التطبيق**
  وليس خوارزمية emWave/Inner Balance المسجّلة. دقته تعتمد كثيراً على طول
  الجلسة وجودة إشارة PPG.
- **طفرات جاما:** تسميتها بـ"لحظات استبصار" اصطلاح استكشافي شائع في أدبيات
  التأمل الشعبية، وليس تصنيفاً عصبياً سريرياً مثبتاً. موجة غاما شديدة الحساسية
  للتشويش العضلي (شد الفك، الحركة)، لذا يُنصح بمراجعة جودة HSI قبل الوثوق
  بطفرة معينة.
- **تزامن الفصين:** التماسك الطيفي الحقيقي (Coherence) يتطلب معدل عينات كافياً
  للإشارة الخام (RAW) بحسب نظرية Nyquist لكل نطاق تردد — مثلاً موجة غاما
  (حتى 44Hz) تحتاج معدل عينات ≥ ~97Hz تقريباً. يقيس التطبيق معدل العينات
  الفعلي من الملف نفسه ويختار الطريقة المناسبة تلقائياً، ويعرض لك أيهما استخدم.
- **مؤشر التكيف العصبي:** معادلة مركّبة (وزن مرجّح قابل للتعديل) من تصميم هذا
  التطبيق حصراً لدمج المؤشرات الثلاثة أعلاه في رقم واحد تعليمي — **وليس مقياساً
  للدونة العصبية الفعلية (Neuroplasticity)** بالمعنى الفسيولوجي الدقيق، والذي
  يتطلب أدوات تصوير دماغي متخصصة (fMRI/qEEG سريري) لإثباته.
- بشكل عام، جميع المؤشرات هنا أدوات **دعم ذاتي واستكشاف تعليمي**، لا بديلاً عن
  استشارة مختص عند وجود أي قلق صحي أو نفسي.
